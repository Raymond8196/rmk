#### Step 2.2: Implement ConnectionManager State Machine

**File**: `rmk/src/wireless/connection_manager.rs`

**Architecture decision**: The ConnectionManager state machine logic lives in `rmk` crate, but the actual task function is generated by codegen. This is because:
- `switch_to_*()` functions use `embassy_nrf::interrupt` types (only in user crate)
- `peripheral.advertise()` uses `trouble_host::Peripheral` (only in user crate)
- `gz_init_default()` / `gz_deinit()` use `rmk_gazell_sys` (only when feature enabled)

The `rmk` crate provides:
- `ManagerState` enum (already defined)
- `SwitchEvent` enum (already defined)
- `SWITCH_CHANNEL` for keyboard→manager communication
- State transition helper functions

The codegen generates the actual async task that:
1. Builds BLE Host once (`stack.build()` → `peripheral` + `runner`)
2. Runs Runner in a loop (errors suppressed during Gazell)
3. Runs ConnectionManager state machine loop
4. Calls `switch_to_*()` functions (codegen'd)
5. Calls `gz_init_default()` / `gz_deinit()` (via `rmk_gazell_sys`)
6. Calls `peripheral.advertise()` (via `trouble_host`)

**State Machine**:

```
                    ┌──────────────┐
          boot ───► │ GazellActive │ ◄─── default
                    └──────┬───────┘
                           │ SwitchEvent::ToBle
                           ▼
                    ┌──────────────┐
                    │SwitchingToBle│ ─── GAZELL_HUB_CANCEL.signal()
                    │              │ ─── wait hub exit
                    │              │ ─── gz_deinit()
                    │              │ ─── settle 200ms
                    │              │ ─── switch_to_ble()
                    └──────┬───────┘
                           │ start advertise
                           ▼
                    ┌──────────────┐
                    │  BleActive   │ ─── advertising / connected
                    └──────┬───────┘
                           │ SwitchEvent::ToGazell
                           ▼
                    ┌──────────────┐
                    │SwitchingToGz │ ─── drop advertiser
                    │              │ ─── settle 200ms
                    │              │ ─── switch_to_gazell()
                    │              │ ─── gz_init_default(1)
                    │              │ ─── restart Gazell hub
                    └──────┬───────┘
                           │
                           ▼
                    ┌──────────────┐
                    │ GazellActive │ ◄─── loop
                    └──────────────┘
```

**Error Recovery** (within SwitchingToBle/SwitchingToGazell):
- On failure: retry up to 3 times with 500ms backoff
- After 3 failures: `ManagerState::Error`, fall back to last known good mode
- Log error via `defmt::error!`

## 5. Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| Embassy 0.10 broke PoC switching pattern | Blocks M1 | Re-verify PoC first (Step 1.1) |
| `trouble_host::Peripheral` can't be moved to spawned task | Blocks M2 | Run ConnectionManager in main joined task (same pattern as Gazell hub) |
| BLE + Gazell binary exceeds 256KB flash | Blocks M2 | Measure early; PoC was 87KB, production codegen should be < 120KB |
| Runner errors during Gazell corrupt BLE state | Intermittent | Suppress errors (PoC pattern proved this works) |
| `peripheral.advertise()` fails after Gazell→BLE switch | Functional | 3x retry with backoff, fallback to Gazell |
| USB HID + USB CDC conflict (Milestone 1) | M1 only | Use USB CDC for PoC (no HID), USB HID for production |
